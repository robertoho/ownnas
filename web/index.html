    Smart features

    These run entirely on this computer: no photo or face leaves it. Their models are downloaded once, when you switch them on, and they work at the indexing speed chosen under Indexing.

    Disk space

    Search index

    OwnNAS keeps a list of every file and folder name, so a search finds them at once however big the library is. It only reads folders that changed since it last looked: changes made through OwnNAS show within seconds, ones made in Finder, Explorer, or another program within five minutes. To read one folder again, right-click it and choose Reindex.

    Words inside files

    OwnNAS also reads the words in text files, PDFs, Word, Excel, PowerPoint, OpenDocument and Pages files, e-books, and emails (and, when tesseract is installed, photos and scans), so a search finds them by what they say. It reads new and changed files after each look for changes. Until a file is read, a search reads it as it goes, which is slower.

    Photos and videos

    Indexing speed

    How hard OwnNAS may work the computer while it indexes the library, looks through it for photos, and makes their thumbnails. Searches and thumbnails you are waiting for always run at full speed.

    Only an administrator can change the speed.
